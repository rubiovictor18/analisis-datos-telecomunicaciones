# analisis-datos-telecomunicaciones
Este proyecto de análisis de datos se centra en explorar y comprender las operaciones de una empresa dedicada a la venta de números virtuales. A través de un análisis exhaustivo de diversos aspectos del negocio, buscamos obtener información valiosa para la toma de decisiones estratégicas.

El estudio abarca el análisis de ingresos y registros diarios para identificar patrones y tendencias. Se realizará una detección y tratamiento de valores atípicos que puedan afectar la fiabilidad de los datos. Asimismo, se investigará la popularidad de los servicios ofrecidos, identificando los más utilizados y los que presentan mayores tasas de cancelación.

Se analizarán los servicios con mayor número de verificaciones y se elaborará un top 20 de los usuarios más destacados, detallando los servicios que prefieren y los métodos de pago más frecuentes que utilizan. Adicionalmente, se examinará la distribución geográfica del uso de los servicios, identificando los países con mayor actividad.

En general, este proyecto aplicará técnicas de inferencia estadística e intervalos de confianza para extraer conclusiones sólidas a partir de los datos disponibles, proporcionando una visión clara del rendimiento del negocio y áreas de oportunidad.
